# Bayesian ETAS and Dynamic Preparedness Priority Index for the Lembang Fault–Bandung City Region

This repository contains the data, code, posterior samples, derived outputs, and manuscript materials used to reproduce the Bayesian spatio-temporal ETAS and Dynamic Preparedness Priority Index (DPPI) analysis for the Lembang Fault and Bandung City, Indonesia.

The workflow separates the regional seismic-process domain from the city-level preparedness application. Bayesian ETAS is conditioned on the regional earthquake catalogue, while population exposure, socioeconomic vulnerability, health critical-facility exposure, and DPPI are evaluated for Bandung City.

## Repository structure

- `analysis/` — complete R and R Markdown workflows and dependency installation helper.
- `data/input/` — audited source inputs used by the analysis. The regional geography input is stored as a compressed GeoPackage (`.gpkg.gz`) and is decompressed automatically by the analysis workflow.
- `data/final/` — derived analysis-ready datasets and geospatial outputs.
- `results/posterior/` — posterior draws and retained raw MCMC chains.
- `results/tables/` — posterior summaries, branching diagnostics, forecast summaries, hindcast results, and sensitivity outputs.
- `results/figures/` — figures generated by the computational workflow.
- `submission_snapshot/` — manuscript snapshot, manuscript-ready figures, tables, and an R Markdown summary.
- `documentation/` — reproducibility and runtime information.

## Main analysis

From the repository root, the complete workflow can be rendered with:

```r
rmarkdown::render(
  "analysis/Lembang_Bayesian_ETAS_DPPI.Rmd",
  params = list(
    project_root = normalizePath("."),
    analysis_mode = "full",
    refit_mcmc = FALSE,
    rebuild_outputs = TRUE
  ),
  envir = new.env()
)
```

Alternatively, run:

```r
source("analysis/RUN_RMD_FROM_REPO_ROOT.R")
```

The default reproducibility mode uses the archived posterior chains. Setting `refit_mcmc = TRUE` performs a new stochastic MCMC fit and can therefore produce small Monte Carlo differences.

## Reproducibility settings

- Random seed: `20260919`
- Primary analysis period: 1 January 2018 to 31 December 2024
- Primary magnitude threshold: `Mcat >= 2.5`
- Strict harmonized sensitivity threshold: `Mw >= 3.4`
- Forecast origin: 1 January 2025
- Primary DPPI posterior propagation: 4,000 draws
- Weight sensitivity: 20,000 Dirichlet(1,1,1,1) weight vectors

The runtime information captured for the reproducible analysis is provided in `documentation/R_SESSION_INFO_FULL_REPRODUCIBLE.txt`.

## Scientific interpretation

The primary ETAS model uses reported catalogue magnitude (`Mcat`) with explicit magnitude provenance. It is not described as a homogeneous moment-magnitude catalogue. The strict harmonized `Mw` subset is retained as a sensitivity analysis.

The ETAS output is interpreted as a conditional finite-horizon seismicity forecast. It is not deterministic earthquake prediction or an earthquake early-warning system. The DPPI is a relative preparedness-priority index combining the short-horizon seismicity component with population exposure, provisional socioeconomic vulnerability, and exposed health critical facilities. It is not expected loss, damage probability, or absolute seismic risk.

## Data provenance

The primary earthquake catalogue is based on the BMKG Indonesian Earthquake Catalog, with magnitude provenance and harmonization recorded in the audited input workbook. Bandung City preparedness indicators are reconstructed from the audited socioeconomic workbook using the source records documented there. Derived files required to reproduce the reported results are included in this repository.
